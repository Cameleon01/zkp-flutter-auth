📦 ÉTAPE 1 : BACKEND (Django)
───────────────────────────────────────────────────────────────

unzip zkauth_backend_final.zip
cd zkauth_backend

# Créer environnement virtuel
python3 -m venv venv
source venv/bin/activate  # Linux/Mac
# OU
venv\Scripts\activate  # Windows

# Installer dépendances
pip install -r requirements.txt

# Créer la base de données
python manage.py makemigrations
python manage.py migrate

# (Optionnel) Créer superuser pour admin
python manage.py createsuperuser

# Lancer le serveur
python manage.py runserver 0.0.0.0:8000

✅ Backend prêt sur http://localhost:8000
✅ Admin disponible sur http://localhost:8000/admin/

═══════════════════════════════════════════════════════════════
🆘 TROUBLESHOOTING
───────────────────────────────────────────────────────────════

❌ Erreur "relation does not exist" (Backend)
   → python manage.py makemigrations
   → python manage.py migrate

❌ Erreur connexion réseau (Frontend)
   → Vérifier IP backend dans login_screen.dart
   → Vérifier firewall (port 8000 ouvert)
   → Tester : curl http://IP:8000/health/

❌ Biométrie ne fonctionne pas (Frontend)
   → Android : Permissions dans AndroidManifest.xml
   → iOS : NSFaceIDUsageDescription dans Info.plist
   → Vérifier appareil supporte biométrie

❌ Token expiré
   → Normal après 24h ou 30min d'inactivité
   → Se reconnecter
